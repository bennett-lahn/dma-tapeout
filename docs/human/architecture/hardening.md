# Local hardening (LibreLane / TTIHP26b)

Condensed runbook for manual ASIC harden / area / GDS. Verbose twin: [`../../llm/13-hardening-librelane.md`](../../llm/13-hardening-librelane.md). Upstream: [TT local hardening](https://www.tinytapeout.com/guides/local-hardening/). Shuttle/PDK: **D27** (`ihp-sg13g2`).

## Stacks (keep separate)

| Job | Tools | Shell |
|---|---|---|
| cocotb / sim | OSS CAD + `test/env.sh` | Main repo |
| Harden / GDS | LibreLane + IHP PDK + `ttihp-verilog-template` | WSL; Nix or Docker |

Do not mix harden Nix/LibreLane into sim shells.

## Layout

- **RTL truth:** `src/rtl/` - copy into `ttihp-verilog-template/src/` before harden
- **TT project:** `ttihp-verilog-template/` (`info.yaml`, `src/config.json`, `src/config_merged.json`, `tt/`)
- **WSL homes:** `~/ttsetup/` (venv + PDK), `~/librelane/` (`nix develop`), `~/tools/oss-cad-suite/` (Yosys + slang)
- Top: `tt_um_lahnb_sgdma`

```bash
cp src/rtl/{types.svh,qspi_engine.sv,sys_controller.sv,top.v} ttihp-verilog-template/src/
```

## Knobs

| Knob | Where | Notes |
|---|---|---|
| Tiles | `info.yaml` → `tiles` | `"1x1"` / `"1x2"` → TT floorplan DEF |
| Clock | `src/config.json` → `CLOCK_PERIOD` | **15.15** ns ≈ **66 MHz** |
| SV packages | `USE_SLANG: true` | Required |
| Merged floorplan | `src/config_merged.json` | Regenerated by `--create-user-config` |

Always re-run `--create-user-config` after changing `tiles` or `config.json`. Running LibreLane on a stale `config_merged.json` hardens the **old** die (seen: `1x1` in yaml, `1x2` DEF in logs).

## Setup once (WSL bash)

TT venv must be **system** Python (`/usr/bin/python3`), not OSS CAD:

```bash
sudo apt install -y python3-tk
/usr/bin/python3 -m venv ~/ttsetup/venv
source ~/ttsetup/venv/bin/activate
pip install -U pip
pip install -r ttihp-verilog-template/tt/requirements.txt
```

PDK: `export PDK_ROOT=~/ttsetup/pdk` and `PDK=ihp-sg13g2` (ciel under that root). LibreLane: `cd ~/librelane && nix develop`. Local `tt/project.py` prefers host Yosys+slang over yowasp for port checks.

## Run

```bash
# A) TT venv - refresh config
source ~/ttsetup/venv/bin/activate
cd ttihp-verilog-template
export PDK_ROOT=~/ttsetup/pdk PDK=ihp-sg13g2
./tt/tt_tool.py --ihp --create-user-config

# B) Nix LibreLane - harden
cd ~/librelane && nix develop
cd /mnt/c/hw_projects/dma-tapeout/ttihp-verilog-template
export PDK_ROOT=~/ttsetup/pdk PDK=ihp-sg13g2
python -m librelane --pdk-root "$PDK_ROOT" --pdk ihp-sg13g2 \
  --run-tag wokwi --force-run-dir runs/wokwi src/config_merged.json

# C) TT venv - reports (avoid nix Python for tt_tool)
source ~/ttsetup/venv/bin/activate
./tt/tt_tool.py --ihp --print-stats
./tt/tt_tool.py --ihp --print-cell-category
```

Docker alternative: `./tt/tt_tool.py --ihp --harden` (default dockerized). Nix: `--harden --no-docker` if that Python has LibreLane + TT deps.

## First audits (2026-08, 66 MHz)

| | Accidental 1x2 | True 1x1 |
|---|---|---|
| Core | ~60k µm² | ~29k µm² |
| Logic pre-fill | ~24k µm² (~40% util) | ~24k µm² (~60% util) |
| DFFs | 158 | 158 |
| Hold delay cells | 236 | 248 |
| Signoff | pass | pass |

Fits **1x1** at 66 MHz; DFF budget comfortable (~158 / ~500 soft), area on 1x1 is tight after fill. Sky130 rehardens do not prove IHP fit or pad timing.

## Pitfalls

- Stale `config_merged.json` → wrong tile DEF
- OSS CAD Python venv → missing `chevron` / broken `tkinter`
- No slang / `USE_SLANG` → `types.svh` parse errors
- Total instances after fill ≠ design size (decap/fill dominate on 1x2)

## Buffer-depth study (optional; not V1 harden)

Optional area vs QPI throughput toolkit: [`../../../scripts/buffer-study/README.md`](../../../scripts/buffer-study/README.md) (`study.py` subcommands `harden`, `max-fit`, `throughput`). It patches **copies** of RTL so `DMA_BUF_DEPTH` (on-chip RX-TX scratch depth `N`) equals `DMA_BUF_DEPTH_MAX`; canonical `src/rtl/` stays at `N=1` for V1. `test/` is import-only. Do **not** run this as part of a normal harden / shuttle signoff; use the sequence above for V1. Verbose twin notes the same pointer.
